# Dialectio — план проєкту

## Ідея
Користувач вводить слово → на карті підсвічуються країни/області → для кожної видно написання,
вимову (IPA/транслітерацію) та аудіо. Пошук іде за **значенням** (concept), а не за рядком,
щоб розрізняти омоніми (коса — волосся / знаряддя / коса на морі).

## Ухвалені рішення (2026-10-05)
- Порядок: спершу мови світу (рівень країн), потім діалекти (рівень областей). Пілот — українська.
- Стек: FastAPI + Next.js + PostgreSQL/PostGIS + MapLibre GL (без Google Maps).
- Мови інтерфейсу: українська, англійська; згодом інші європейські.
- Бюджет: до ~20 $/міс; лише відкриті/безкоштовні джерела даних.
- Аудіо: живі записи (Lingua Libre, Wikimedia Commons, користувачі); TTS як запасний варіант з позначкою «синтезовано».
- Розробник один, ~5–10 год/тиждень → дрібні задачі (1–3 год), ведуться як GitHub Issues.

## Модель даних
| Сутність        | Поля (основні)                                                        |
|-----------------|-----------------------------------------------------------------------|
| Concept         | id, gloss (uk/en), wikidata_id, category                              |
| Variety         | id, name, iso639_3, glottocode, parent_id (мова → наріччя → говір)    |
| Region          | id, name, level (country/adm1/adm2), code, geometry (PostGIS)         |
| VarietyRegion   | variety_id, region_id                                                 |
| Form            | id, concept_id, variety_id, spelling, ipa, transliteration, source_id |
| Audio           | id, form_id, url, speaker, is_synthetic, license, source_id           |
| Source          | id, name, url, license                                                |

## Подальший розвиток (план від 2026-10-11)

Напрям: **поєднання**. Світовий рівень («слова світу», кольори за походженням) приводить трафік;
українські говори — унікальна глибина, яку згодом повторюємо для інших мов.

Головний принцип: **одне слово = одна сторінка = один перегляд**. Карта — інструмент на сторінці,
а не одна «вічна» сторінка: кожен перехід до іншого слова — справжня навігація з новою адресою,
власним заголовком, текстом для Google і новим показом реклами. Клік по області в межах слова —
фільтр на тій самій сторінці (це не нове слово).

## Ризики
- Ліцензії (CC BY-SA → атрибуція і share-alike; авторське право на словники).
- Якість діалектних даних → модерація.
- Політично чутливі межі → явно вказувати джерело меж.
- Тонкі або дубльовані сторінки (слово без тексту, однакові сторінки з різними `?region=`) → Google їх не індексує: на кожній сторінці має бути унікальний текст, варіанти з параметрами — через canonical.
- Помилки в «≈»-словах на світовому рівні помітять носії мов → спершу показувати перевірені слова, неперевірені — з явною позначкою.
- Відповіді ШІ в пошуку забирають прості запити «як буде X мовою Y» → ставка на те, чого ШІ не дає: карта, живі голоси, діалекти.
